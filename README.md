# PlantsApp 🌱

PlantsApp is an iOS app that helps users organize their plants and track watering tasks. It was developed for Challenge 2 at the Apple Developer Academy using interface designs provided by the Academy.

## Main Features

- Add plants with a name, room, light requirements, watering frequency, and water amount.
- View plant care information in a list.
- Mark plants as watered or undo the action.
- Track watering completion with an animated progress bar.
- Edit existing plant reminders.
- Delete plants using swipe actions.
- Save plant information and watering completion between app launches.
- Use Liquid Glass buttons in a dark interface.

## Technologies Used

- Swift and SwiftUI
- MVVM architecture
- Observation framework
- Codable and UserDefaults for local storage
- SF Symbols
- Liquid Glass
- UserNotifications for local reminder scheduling

## Development Status

Local watering notifications have been implemented. Notification delivery is still being verified.
